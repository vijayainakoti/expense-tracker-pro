# 💰 Expense Tracker Pro

A Personal Finance Management System built using Python, Tkinter, SQLite, and Matplotlib.

## Features
- Add / Update / Delete expenses
- Category tracking
- Date filtering
- Graphs (Bar & Pie charts)
- Export to CSV
- SQLite database storage

## Tech Stack
- Python
- Tkinter
- SQLite
- Matplotlib

## How to run
```bash
python expense_tracker.py
